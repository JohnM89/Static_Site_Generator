# Static Site Generator

A simple static site generated with Python static site generator

## Features
- Markdown-to-HTML conversion for pages and blog posts

## Project Structure
content/         # Source markdown (pages and blog posts)
static/          # CSS and images to copy as-is
src/             # Generator code (Python)
docs/            # Built site (GitHub Pages source)
template.html    # HTML layout template
build.sh         # Production build (sets base path; edit)

## Local Development
Build to the default root (`/`) and run main.sh
